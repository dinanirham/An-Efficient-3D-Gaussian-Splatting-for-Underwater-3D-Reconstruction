02 Key modifications vs. vanilla 3DGS

  1. Depth from the same rasterizer. render_depth() reuses the RGB rasterizer but overrides Gaussian colors with camera-space Z, giving a differentiable depth map with no extra CUDA code. (gaussian_renderer/__init__.py:109)
  2. Physically grounded image formation. The render is treated as clear scene radiance J, then degraded: underwater = J·exp(-β_d·z) + B_inf·(1-exp(-β_b·z)). Reconstruction loss compares this re-degraded image to the ground-truth photo, so the Gaussians learn the clean scene. (deepseecolor/models.py)
  3. Two-phase training gated by seathru_from_iter. Plain 3DGS first; then the underwater nets switch on, GS params briefly freeze/unfreeze, and GS colors are re-adjusted for color correction. (train.py:180-192, 456-463)
  4. Three separate optimizers. Gaussians, the backscatter+attenuation nets (alternating schedule via update_bs_at_interval), and the learned background — which hands off to B_inf once Sea-Thru activates (bg_from_bs).
  5. Restoration priors. The single reconstruction objective is joined by a stack of underwater-specific losses: dark-channel, gray-world, saturation, and alpha-background.
